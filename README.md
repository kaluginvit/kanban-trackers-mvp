# Kanban Trackers MVP Portfolio (FGIp07)

Три рабочих прототипа кастомных трекеров задач с канбан-доской и ролевой моделью (RBAC):

1. **EduFlow (`tracker-school/`)** — трекер производственного цикла онлайн-школы (5 этапов, 4 роли, дедлайны, комментарии, `localStorage`).
2. **StroyControl PWA (`tracker-construction/`)** — трекер строительных объектов (6 этапов, чек-листы технадзора, GPS-фото, имитация офлайн-очереди).
3. **DevSprint (`tracker-agency/`)** — трекер спринтов IT-агентства (Backlog → Done, симуляция GitHub PR, тайм-трекер План/Факт, клиентский Read-only режим).

**Live Demo (GitHub Pages):** https://kaluginvit.github.io/kanban-trackers-mvp/
